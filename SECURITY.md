# Security Policy — Zyvor Fabric

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | Yes |
| < 0.2   | Best-effort |

## Reporting a vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Email **security@zyvor.dev** (or use GitHub Security Advisories on
`zyvorai/fabric`) with:

- Affected component (fabricd, web, operator, chart, terraform-provider)
- Description and impact
- Reproduction steps or PoC (private)
- Your preferred contact

We aim to acknowledge within **3 business days** and provide a remediation
timeline after triage.

Longer security assessments and design notes live under `docs/security.md`
and related docs; this file is for reporting and supported versions only.
