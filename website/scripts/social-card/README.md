# Social cards

`compare.html` is the source for `../../static/img/compare-social.png` (1200×630).

Re-render after editing (macOS, Google Chrome installed):

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --hide-scrollbars --window-size=1200,630 --force-device-scale-factor=1 \
  --screenshot="$PWD/../../static/img/compare-social.png" "file://$PWD/compare.html"
```
