WebSocket Channels

Terminal Console

xterm.js-based terminal access to VMs over WebSocket. Authenticated with JWT. Supports resize events.

VNC Console

noVNC proxy for graphical desktop access. Proxied through Zyvor Fabric with token-based authentication.

Real-time Events

Live VM state changes, metrics updates, and alert notifications pushed to connected clients.

Authentication

  • JWT Bearer tokens on all endpoints
  • WebSocket auth via query parameter or upgrade header
  • API keys for service-to-service calls
  • Rate limiting: 5 attempts / 5 minutes on auth

Security Model

Defense in depth, validated by 31-round audit

Authentication

  • PAM integration for system user authentication
  • JWT tokens with configurable expiration
  • Token revocation and blacklisting
  • bcrypt password hashing (cost factor 12)
  • LDAP and OIDC/OAuth2 for enterprise SSO
  • API keys with scoped permissions

Authorization

  • Admin -- full platform access
  • User -- VM operations, limited config
  • Viewer -- read-only access
  • RBAC enforced on every API endpoint
  • Multi-tenancy with project isolation

Input Validation

  • Every user-facing parameter validated
  • Command injection prevention (no shell pipelines)
  • Path traversal protection with canonicalization
  • SSRF prevention on user-provided URLs
  • SQL injection prevention (parameterized queries)
  • Entity ID sanitization in state store

Operational Security

  • Audit logging on all lifecycle operations
  • Credential redaction in API responses
  • Auto-generated secrets with 0600 permissions
  • Security headers on all HTTP responses
  • Rate limiting on authentication endpoints
  • TLS certificate management built in

Networking Stack

8 dedicated crates for enterprise networking

Network Policy

Cilium-style label-based ingress/egress rules. Define which VMs can communicate using selectors and rules.

VM Firewall

Per-VM firewall profiles and zones implemented via nftables. Stateful inspection with connection tracking.

Service Mesh

Virtual IP load balancing with round-robin, least-connections, random, and IP-hash algorithms.

VPN Mesh

WireGuard tunnels with point-to-point, hub-spoke, and full-mesh topologies for secure inter-VM networking.

Traffic Shaping

QoS with guaranteed/maximum rates, burst capacity, and priority-based bandwidth allocation per VM.

DNS Policy

Zone management, upstream server configuration, and domain blocking for VM DNS resolution control.

NAT Gateway

Masquerade, SNAT, DNAT, and hairpin NAT for flexible network address translation configurations.

Net Monitor

Per-VM bandwidth tracking with configurable threshold alerts and historical usage data.

Why Rust Matters

  • Zero-cost abstractions -- high-level code compiles to optimal machine code
  • No garbage collector -- deterministic performance with no stop-the-world pauses
  • Async/await -- Tokio runtime handles thousands of concurrent connections
  • Memory safety -- compile-time guarantees eliminate runtime crashes
  • Safe concurrency -- data races caught at compile time

Concurrency Model

  • Tokio multi-threaded async runtime
  • Per-VM mutexes prevent race conditions
  • Lock manager for coordinated operations
  • Async D-Bus calls to systemd
  • Non-blocking I/O throughout the stack

Scalability

  • Tested with hundreds of concurrent VMs
  • Linear scaling with available hardware
  • Minimal overhead per managed VM
