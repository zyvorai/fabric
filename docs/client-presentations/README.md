## Usage Notes

- Open any `.html` file directly in a browser for full-screen presentation
- Use `Ctrl+P` / `Cmd+P` to print or export to PDF (print styles included)
- Each "slide" is a full-viewport section -- scroll down to advance
- All presentations use consistent branding and color scheme
- Recommended browser: Chrome, Firefox, or Edge (latest versions)

## Presentation Order for Full Briefing

For a comprehensive client briefing (2-3 hours), present in this order:

1. **Executive Overview** (15 min) -- set the stage
2. **Technical Architecture** (30 min) -- build credibility
3. **Feature Deep Dive** (30 min) -- showcase capabilities
4. **Security & Compliance** (20 min) -- address concerns
5. **Competitive Analysis** (15 min) -- differentiate
6. **Live Demo** (30 min) -- prove it works
7. **Deployment Guide** (15 min) -- path to production

## Quick Pitch (30 minutes)

For a shorter pitch, use:

1. **Executive Overview** (15 min)
2. **Live Demo** (15 min)
