Key Benefits

Dramatically Lower TCO

No license fees (MIT). Single binary eliminates infrastructure sprawl. One engineer can manage what previously required a team.

Deploy in Minutes, Not Days

One command deploys the full platform. No package conflicts, no database servers, no message queues. Works on any Linux with systemd.

Memory-Safe by Design

Built in Rust with zero unsafe code. Eliminates entire categories of security vulnerabilities -- buffer overflows, use-after-free, data races.

systemd-Native Architecture

VMs are first-class systemd units. Journal logging, watchdog support, and socket activation come free. No custom hypervisor to maintain.

Enterprise Features, Zero Bloat

HA clustering, live migration, GPU passthrough, LDAP/OIDC SSO, multi-tenancy, and network policies -- without the complexity.

Five Management Interfaces

CLI, terminal UI, web dashboard, Kubernetes operator, and Terraform provider. Every team uses their preferred workflow.

Use Cases

Development and Testing

Spin up disposable VM environments in seconds. cloud-init integration means VMs come up pre-configured. Templates enable consistent environments across the team.

Edge and Branch Office

Single-binary deployment is ideal for remote sites with limited IT staff. Runs on minimal hardware with a 20MB memory footprint. Manage remotely via API.

Private Cloud

Multi-node clustering with HA, live migration, and shared storage delivers a private cloud experience without OpenStack complexity.

VMware Migration

Import existing VMs from VMDK format. Familiar web UI eases the transition. REST API enables automated migration at scale. MIT license eliminates recurring costs.

CI/CD Infrastructure

API-first design integrates with Jenkins, GitLab CI, and GitHub Actions. Terraform provider enables infrastructure-as-code workflows.

Managed Service Providers

Multi-tenancy with project isolation, resource quotas, and RBAC. White-label the web UI. Automated backups and monitoring reduce operational overhead.
